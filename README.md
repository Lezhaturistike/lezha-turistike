# Lezha Turistike

Platformë digjitale për promovimin dhe eksplorimin e trashëgimisë turistike, historike, arkeologjike dhe kulturore të Lezhës.


Platforma ofron përmbajtje në shqip dhe anglisht, eksperienca interaktive, WebGIS dhe mjete digjitale për eksplorimin dhe planifikimin e vizitës.
